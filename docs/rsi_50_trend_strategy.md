# RSI 50 附近日线顺趋势交易

## 适用范围

本策略固定在日线周期执行，只记录 RSI 50 附近顺趋势交易相关规则。

## 指标参数

- RSI：RSI(14)
- 均线：MA20、MA30
- 波动率：ATR(14)
- RSI 50 附近：45–55

## 日线摆动点

日线摆动点采用 3/3：

- 摆动高点：当前最高价高于左侧 3 根日线的最高价，并且高于或等于右侧 3 根日线的最高价。
- 摆动低点：当前最低价低于左侧 3 根日线的最低价，并且低于或等于右侧 3 根日线的最低价。
- 摆动点需要等待右侧 3 根日线完成后才能确认，因此至少延迟 3 个交易日。

## W 底

- 使用两个已确认的摆动低点 L1、L2。
- L2 出现在 L1 之后 5–30 根日线内。
- 两个低点的价差不超过 1 ATR。
- 两个低点之间的反弹幅度至少为 1 ATR。
- 第二个低点可以与第一个低点接近，或形成更高低点。
- 颈线是 L1 与 L2 之间的最高价。

## M 顶

- 使用两个已确认的摆动高点 H1、H2。
- H2 出现在 H1 之后 5–30 根日线内。
- 两个高点的价差不超过 1 ATR。
- 两个高点之间的回撤幅度至少为 1 ATR。
- 第二个高点可以与第一个高点接近，或形成更低高点。
- 颈线是 H1 与 H2 之间的最低价。

## 多头信号

以下条件需要同时满足：

1. MA20 和 MA30 的斜率向上。
2. RSI 回落至 45–55。
3. 价格形成 W 底，第二个底部可以是更高低点。
4. 收盘价高于 W 底颈线加 0.1 ATR，不能使用盘中最高价触发。
5. RSI 同时重新站上 55。

## 空头信号

以下条件需要同时满足：

1. MA20 和 MA30 的斜率向下。
2. RSI 反弹至 45–55。
3. 价格形成 M 顶，第二个顶部可以是更低高点。
4. 收盘价低于 M 顶颈线减 0.1 ATR，不能使用盘中最低价触发。
5. RSI 同时跌破 45。

## 核心逻辑

RSI 到达 50 附近不能单独触发交易。RSI 45–55 只表示趋势中的回踩或反抽区域，必须同时得到均线趋势、W/M 价格形态、收盘突破和 RSI 动量的确认。
