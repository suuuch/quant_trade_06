# A股信号

规则

# 高位 M 顶做空

候选条件同时满足2个：

- RSI\(14\) 最近进入 75–85

- 第二高点对应 RSI 低于第一高点，形成顶背离

确认条件：

- 收盘价跌破两个顶部之间的颈线

- 或 MA20 下穿 MA30

- 突破K线成交量高于20周期均量

止损参考：第二个顶部上方 0\.5 ATR。

不要在第二个顶部刚出现时直接判空，必须等待颈线确认。

# 低位W底做多

候选条件同时满足2个：

- RSI\(14\) 最近进入 15–25

- 第二高点对应 RSI 低于第一高点，形成顶背离

确认条件：

- 收盘价高于两个底部之间的颈线

- 或 MA20 上穿 MA30

- 突破K线成交量高于20周期均量

止损参考：第二个底部下方 0\.5 ATR。

# RSI 顺势交易

只使用日线 RSI(14) 和 MA20 日均涨跌幅筛选；W/M 形态、MA30、价格突破等其他条件不参与。

多头：

- 最新一天 RSI 位于 42–58（含边界）

- MA20 过去 10 天平均每天上涨 1% 或以上

- 最近 5 天 RSI 全部位于 50–58（含边界），不能少于 5 天

空头：

- 最新一天 RSI 位于 42–58（含边界）

- MA20 过去 10 天平均每天下跌 1% 或以上

- 最近 5 天 RSI 全部位于 42–50（含边界），不能少于 5 天

这里的逻辑不是“RSI 到 50 就交易”，而是先用最新 RSI 42–58 限定候选，再要求 MA20 方向足够明确，并要求最近 5 天 RSI 持续落在方向区间。



# RSI低于40

不能直接定义为做空信号，应该拆成两类。

趋势延续空：

- RSI \< 40

- MA20 \< MA30

- 价格跌破最近摆动低点

- RSI也同步创新低

- 没有明显底背离

潜在反转观察：

- 价格创新低

- RSI没有创新低

- 两个低点间隔至少5根K线

- RSI第二低点比第一低点高至少3点

这是底背离，只进入观察状态，不立即做多。做多还需满足：

- RSI重新站上40

- 价格突破最近一个更低高点

- 或出现 W 底颈线突破

# 横盘后继续下跌

“RSI小反弹后会跌得更狠”不能直接作为规则。建议定义成空头旗形：

- 前面存在至少 2 ATR 的快速下跌

- 随后横盘 5–20 根K线

- 横盘振幅小于 1\.5 ATR

- RSI从低位反弹，但始终没有站上50

- MA20和MA30继续向下

- 收盘跌破横盘下沿

只有跌破横盘下沿才触发续跌信号。若价格向上突破横盘区，则做空逻辑失效。

# 日线背离、小时级入场

采用“双周期”，不要让日线背离直接产生订单。

日线负责方向：

- 日线出现底背离：未来只关注小时级做多

- 日线出现顶背离：未来只关注小时级做空

- 日线信号有效期建议为 5–15 个交易日

小时线负责触发：

- 日线底背离 \+ 小时 W 底突破 \+ RSI站上50 → 多头信号

- 日线顶背离 \+ 小时 M 顶跌破 \+ RSI跌破50 → 空头信号

这样能减少日线背离出现后，价格继续沿原趋势运行造成的过早入场。

# “三波、第三次背离”

波浪理论主观性太强，程序中建议替换为“三次摆动衰竭”：

空头衰竭：

- 价格连续形成三个更低低点

- 第三个低点创新低

- RSI第三个低点高于第二个低点

- 第三段跌幅小于第二段跌幅

- 第三段成交量或动量没有同步增强

这只能标记为“高优先级反转观察”，不能直接做多。必须等待价格突破最后一个更低高点。

顶部使用完全相反的规则。







**信号出现**

标的：\*\*\*

周期：1天/1小时

方向：做多观察

信号出现：高位 M 顶做空 

确立条件：RSI\(14\) 最近进入 75–85，且第二高点对应 RSI 低于第一高点，形成顶背离

日线环境：底背离

小时形态：W底已突破

RSI：52\.6，重新站上50

失效位置：W底第二低点

# 一些伪代码

1. 颈线怎么定义

颈线就是两个顶部之间的最低价：

`neckline = min(low[H1_index:H2_index + 1])`

例如：

第一个顶部：100

两个顶部之间最低价：92

第二个顶部：99

颈线：92

不能把两个高点的连线称为颈线。M顶的颈线位于中间回撤低点。

2. 何时确认跌破

不要用盘中最低价碰到颈线就触发。

建议要求：

`收盘价 < 颈线 - 0.1 × ATR(14)`

更严格的版本：

连续两根K线收盘低于颈线

或者：

一根K线收盘跌破颈线，并且成交量 \> 20周期平均成交量

3. 完整M顶空头规则

    1. 找到确认摆动高点 H1

    2. 之后5–30根K线内找到 H2

    3. H1与H2的价差不超过1 ATR

    4. 中间回撤至少1 ATR

    5. H1或H2附近RSI达到70以上

    6. H2对应的RSI低于H1，优先级提高

    7. 收盘价跌破中间最低点形成的颈线

    8. MA20向下，或价格处于MA20下方

才产生空头信号

失效条件：

收盘价重新突破 H1、H2 中较高者 \+ 0\.3 ATR

核心参数建议先固定为：

```Plain Text
pivot_left = 3
pivot_right = 3
min_top_distance = 5
max_top_distance = 30
max_top_difference = 1.0 ATR
min_middle_pullback = 1.0 ATR
break_buffer = 0.1 ATR
```



这样“顶部”“时间长度”“颈线”和“跌破”都有明确数字，可以直接写进程序并进行回测。

3根会不会太少？某根K线的最高价，

大于它左侧3根K线的最高价，

同时大于或等于右侧3根K线的最高价，

则它是确认高点。 



会。

左右各3根只是“快速摆动高点”，在15分钟、1小时等噪声较大的周期里容易识别出过多小高点，产生很多伪 M 顶。



不过增加根数也有代价：左右各 N 根意味着高点至少延迟 N 根K线才能确认。

例如1小时图：

```Plain Text
3/3：延迟3小时，灵敏但噪声多
5/5：延迟5小时，相对均衡
8/8：延迟8小时，形态更可靠但明显滞后
```



建议参数

```Plain Text
K线周期        左右确认根数        用途
5分钟        7–10        过滤盘中噪声
15分钟        5–8        短线监控
1小时        5        推荐默认值
4小时        3–5        波段监控
日线        3–5        中期结构
```





你的策略包含日线和小时线，建议：

日线：Pivot High 采用 3/3

小时线：Pivot High 采用 5/5

不要只靠根数

单纯把3根改成5根仍然不够。最好增加“突出程度”，过滤很小的局部波动。

小时线高点建议定义为：

1. 当前最高价大于左侧5根K线的最高价

2. 当前最高价大于或等于右侧5根K线的最高价

3. 高点相对前后局部低点的突出幅度至少为 0\.8 ATR



伪代码：

```Plain Text
is_pivot_high = (
    high[i] > max(high[i-5:i])
    and high[i] >= max(high[i+1:i+6])
)

left_low = min(low[i-5:i+1])
right_low = min(low[i:i+6])

prominence = high[i] - max(left_low, right_low)

confirmed_high = (
    is_pivot_high
    and prominence >= 0.8 * atr[i]
)
```



这里的 prominence 可以理解为：这个顶部必须真的从附近价格中“凸出来”，不能只是比旁边高一点点。

M顶进一步过滤

即使找到两个确认高点，也需要：

两顶间隔：至少10根、最多60根小时K线

两顶高度差：不超过1 ATR

中间回撤：至少1\.2 ATR

第二顶不能出现在第一个顶部确认之前

最终必须收盘跌破颈线

小时线推荐采用：

```Plain Text
pivot_left = 5
pivot_right = 5
min_top_distance = 10
max_top_distance = 60
min_prominence = 0.8 ATR
min_middle_pullback = 1.2 ATR
max_top_difference = 1.0 ATR
```
